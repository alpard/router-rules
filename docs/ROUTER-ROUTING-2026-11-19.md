# RouteRich: TheForceful subscription and AI routing

Дата проверки: 2026-11-19

## Цель

Перенести AI-трафик на новую подписку TheForceful, сохранив общую логику маршрутизации:

- пользовательские списки, которые ранее направлялись через MHC ZA, должны направляться через TheForceful;
- при недоступности текущего маршрута трафик должен переходить на следующий маршрут по цепочке;
- после восстановления маршрута должна сохраняться предусмотренная автоматическая логика выбора;
- устройства должны получать одинаковое поведение независимо от того, подключены они по Wi-Fi или кабелю.

## Зафиксированная конфигурация ZeroBlock

Роутер: RouteRich AX3000  
Версия ZeroBlock: v0.8.3-r164  
Дата: 2026-11-19

Секции:
- `mhc_za` — существующий основной контур MHC ZA;
- `awg10` — существующий VPN-маршрут;
- `theforceful` — новая подписка TheForceful.

Для `theforceful` включён режим subscription с несколькими узлами и URLTest:
- интервал проверки: 30 секунд;
- tolerance: 100 мс;
- testing URL: Cloudflare generate_204;
- список узлов загружается из подписки.

Для AI-направления в секции TheForceful сформирован текстовый список доменов:
- api.ipify.org;
- chatgpt.com;
- openai.com;
- oaistatic.com;
- oaiusercontent.com;
- gemini.google.com;
- aistudio.google.com;
- makersuite.google.com;
- bard.google.com;
- labs.google.com;
- notebooklm.google.com;
- ai.google.dev;
- generativelanguage.googleapis.com.

В конфигурации был также включён community list `ai`. Первоначальная попытка добавить его в TheForceful одновременно с MHC ZA вызвала ошибку ZeroBlock о дублировании community list. После этого список был привязан к TheForceful; в последующей генерации маршрутов присутствуют `community-theforceful-ai`, `community-ip-theforceful-ai` и `user-domains-text-theforceful`.

## Результат проверки

На 2026-11-19 пользователь подтвердил, что ChatGPT открывается:
- на iPad;
- на компьютере.

Это подтверждает работоспособность AI-маршрута на двух устройствах в момент проверки.

## Что ещё не подтверждено

Автоматическое переключение между маршрутами при полном отказе TheForceful и возврат после восстановления не проверялись. Нельзя считать failover завершённым только по факту успешного открытия ChatGPT.

Также отдельно требуется подтвердить, что все пользовательские списки, ранее шедшие через MHC ZA, переведены на TheForceful без нарушения приоритетов и исключений.

## Следующие проверки

1. Проверить внешний IP для AI-доменов на iPad и компьютере и убедиться, что он соответствует выходному узлу TheForceful.
2. Проверить, что остальные категории и пользовательские списки продолжают идти по ожидаемым маршрутам.
3. Провести контролируемый тест недоступности TheForceful и проверить переход на следующий маршрут.
4. Проверить восстановление TheForceful и возврат к штатной логике выбора.
5. Проверить, что устройство 192.168.1.205 не исключено из нового маршрута и обрабатывается так же, как остальные устройства.

## Безопасность

Не сохранять в Git:
- URL подписки;
- UUID, пароли, токены и ключи;
- API secret ZeroBlock;
- полный экспорт `/etc/config/zeroblock`, если он содержит секреты.

Перед изменениями конфигурации роутера создавать резервную копию `/etc/config/zeroblock`.
